## Overview

A local Q&A demo that streams tokens from inside the sandbox. It is meant for verifying the Preview / Eval / Code surface, not for production answers.

## How it works

Replies are generated in-process. There is no LLM call and no tool loop — the agent implements the same `stream()` contract as live agents so the docs preview and eval runner stay identical.

## Environment

None. The sandbox preview runs without API keys.
